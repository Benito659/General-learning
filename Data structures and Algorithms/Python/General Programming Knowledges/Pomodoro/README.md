## Pomodoro
Pomodoro (which means tomato in italian) is a time management technique based a 25 minute timeslots. If you're working remote or working as a developer then you might like what it has to offer.


### Planning
- when i start a task
- it is good to spend only 25 min on that task
- i should list task of things i should do
- things you want to get done today or thing you want to get done in the long run
- when doing pomodoro, you should plan th task first
- i list all the task
- when a task is too big i subsivise it
- at the end i check up on stuff i have plan and how many of them i have achieve

### TimeBoxing
- give as much as time as possible for a large task and time box it

### Concentration
- the tasks need to be done in concentration mode
- turn off slack, app, browsers tabs not needed, notifications

### Breacks
- You should take a break of 5 min
