## UV
uv is an extremely fast, all-in-one Python package and project manager written in Rust by Astral (the creators of Ruff). It is designed to replace multiple fragmented tools in the Python ecosystem, acting as a direct replacement for pip, virtualenv, pipx, poetry, and pyenv

### Features and capability
- Unmatched Speed
- Environment Management: It automatically creates, manages, and tracks virtual environments
- Project & Dependency Management: It handles building projects and supports reproducible dependency locks with pyproject.toml and uv.lock files, similar to Cargo (Rust) or npm (Node.js).
- Python Installation: It can download and manage multiple versions of Python directly, meaning you no longer need pyenv
- Tool & Script Execution: You can install, run, and upgrade Python applications globally (like pipx), or run single-file scripts with inline dependency metadata.
- Drop-in pip Replacement: If you are happy with pip, you can use uv pip as a drop-in command with no disruption to your existing workflow.

### Install UV
-  macOS / Linux: Run 
```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
```
- Windows:
```bash
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
- brew : 
```bash
    brew install uv
```

### Run Virtual environnement
- you can start virtual environement
- you can run that environement
- you can install library 
```bash
    uv venv
    source .venv/bin/activate
    uv pip install scikit-learn
```

### Run a specific script
- normally to run a script we have to create a virtual environement first
- we can run a specific script  with **uv** providing it dependencies
- we can also specify versions
```bash
    uv run --with requests --with rich script.py
```
- the script
```python
    import requests
    from rich.pretty import pprint

    resp = requests.get("https://peps.python.org/api/peps.json")
    data = resp.json()
    pprint([(k, v["title"]) for k, v in data.items()][:10])
```

- We can also add metadata on top of the script if we don't want to pass the depedency into the command line but define it directly into the file
```python
    # /// script
    # requires-python = ">=3.12"
    # dependencies = [
    #   "requests<3",
    #   "rich",
    # ]
    # ///

    import requests
    from rich.pretty import pprint

    resp = requests.get("https://peps.python.org/api/peps.json")
    data = resp.json()
    pprint([(k, v["title"]) for k, v in data.items()][:10])

```
- Command :
```bash
    uv run script.py
```

- one technique is that if you have a specific scripts that have a lot of dependencies and that dependencies doesn't need to go to the main file , you can run it quickly with uv



### Github actions 
- Uv can really improve the speed up of your ci\cd pipeline
```yml
name: Code Checks

on:
  push:
    branches:
    - main
  pull_request:
    branches:
    - main

jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.11", "3.12"]

    steps:
    - uses: actions/checkout@v2
    - name: Install uv
      uses: astral-sh/setup-uv@v2
    - name: Set up Python ${{ matrix.python-version }}
      run: uv python install ${{ matrix.python-version }}
    - name: Install Venv
      run: uv venv
    - name: Install Dependencies
      run: uv pip install -e ".[dev]"
    - name: Test
      run: uv run pytest

```

-  **astral-sh/setup-uv@v2** step to ensure that uv is installed in the runner. 
- From there you can use UV as you would normally.
-  uv run command can also be useful in this context.



### Sync
- Uv have same functionnalities as Pip-tools
- It can generate verbose requirements files 
- It can also sync your dependencies for you
- We can generate a requirements.txt file from this requirements.in file by running
```bash
    uv pip compile requirements.in
```
```txt
# This file was autogenerated by uv via the following command:
#    uv pip compile requirements.in
joblib==1.4.2
    # via scikit-learn
numpy==1.26.4
    # via
    #   scikit-learn
    #   scipy
scikit-learn==1.4.0
    # via -r requirements.in
scipy==1.14.1
    # via scikit-learn
threadpoolctl==3.5.0
    # via scikit-learn
```

- Sync command
```bash
    uv pip sync requirements.txt
```
- This command will install the dependencies from the requirements.txt file but it will also remove any package that is not listed
