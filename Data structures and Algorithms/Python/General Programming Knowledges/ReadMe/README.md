### KeyBoard Short
- Markdown is superset of html
- Not evry thing in html have a markdown shortcut
- I will ad a keyboard shortcut
- This html will render as a button on your keyboard
```html
    <kbd>CMD/CTRL</kbd> + <kbd>C</kbd>: to copy
    <kbd>CMD/CTRL</kbd> + <kbd>V</kbd>: to paste
```
- Another exemple : to hide a part and details it only if user want
```html
    <details>
    <summary><b>Need help with copy/paste?</b></summary>

    - <kbd>CMD/CTRL</kbd> + <kbd>C</kbd>: to copy
```
